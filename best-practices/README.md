# Best Practices

Team standards — "we do it this way". If you disagree, raise it in the team and update the doc; don't silently diverge.

| Folder | Scope |
| --- | --- |
| [coding/](coding/) | Power Fx, C# (plugins, business logic), AL conventions |
| [testing/](testing/) | Test strategy: plugin unit tests, app regression checks |
| [security/](security/) | Security roles, field-level security, auditing, data handling |
| [delivery/](delivery/) | ALM: solution strategy, branching, CI/CD pipelines |

Each folder holds the standard for its area. Keep entries short and actionable — a checklist beats an essay.
