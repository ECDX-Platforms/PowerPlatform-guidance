# Project Template

Starting point for a new app or project. Copy this layout into the new repo, then fill in `README.md` from `readme-template.md`.

Recommended layout for a new project:

```
my-project/
├── README.md            # from readme-template.md below
├── solutions/           # managed/unmanaged solution files (.zip)
├── docs/                # project-specific ADRs and notes
└── pipelines/           # CI/CD for this project (from templates/pipelines/)
```

- `readme-template.md` — copy as the project README and replace the `<placeholders>`.
