# Templates

Boilerplate for starting new work. Copy, rename, adapt — don't edit in place.

| Folder | Use for |
| --- | --- |
| [project/](project/) | Scaffolding a new app/project repo or folder |
| [docs/](docs/) | ADR, RFC, and runbook documents |
| [pipelines/](pipelines/) | Azure DevOps pipeline YAML for solution CI/CD |

## Rules

- Templates are the team's agreed starting point. Improvements belong here, not in the copied project — propose them as changes to this repo.
- Every template folder has a README explaining when and how to use it.
