# Documentation

Knowledge and explanations. Team standards live in [../best-practices/](../best-practices/) — keep "how do I" separate from "we agree to".

| Folder | Contents |
| --- | --- |
| [architecture/](architecture/) | Architecture Decision Records (ADRs), system overviews, environment topology |
| [guides/](guides/) | How-to guides and onboarding material (Dataverse, Canvas Apps, Model-Driven Apps, ALM) |
| [reference/](reference/) | Glossary, connector and API references, configuration cheat sheets |

## Adding a document

- Name files in `kebab-case.md`.
- Put ADRs in `architecture/` as `adr-NNN-short-title.md`, starting from [templates/docs/adr-template.md](../templates/docs/adr-template.md).
